# Contributing to Research Notes

This repository is a public research narrative. Contributions should improve clarity, reproducibility, references, examples, or tooling without rewriting the evidentiary history.

## Editorial rules

- Preserve the chronology of discoveries and later corrections.
- Keep formal results, observations, assumptions, and hypotheses visibly distinct.
- Do not strengthen a claim beyond the cited experiment or theorem.
- Treat runnable teaching examples as synthetic unless an exact public reproduction is identified.
- Keep private experiment artifacts and active unpublished research out of public pull requests.

## Technical changes

Run the publication validation/tests relevant to the files changed. Notebook edits should remain renderable and deterministic where the repository tooling expects generated examples.

For theorem corrections, update the cross-reference to Theorem Library rather than copying proof source into this repository.
