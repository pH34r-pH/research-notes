# Concept map

The repository has two reading layers.

## Narrative layer

The notebooks answer “why did this question become worth asking next?”

## Reference layer

The `reference/` directory answers “what does this concept mean independently of one notebook?”

Current reusable areas include:

- representation, readout, and consumer;
- probes, selectivity, held-out evaluation, controls, and ablations;
- accessibility versus use;
- formal-method boundaries;
- normalization geometry and public formal checkpoints.

## Cross-repository formal layer

When a result is promoted to public machine-checkable mathematics:

```text
research-notes
  explains why the theorem matters
        |
        v
theorem-library
  contains the public Lean proof
        |
        v
private research ledger/lab
  retains lifecycle/correspondence state
```

This avoids duplicating theorem statements or privately active research queues into the public narrative.
