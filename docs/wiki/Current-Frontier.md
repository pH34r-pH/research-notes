# Current frontier

The public chronology currently ends at a bounded distinction: useful task information can be accessible in a frozen state while the native consumer underuses it.

The next research question is therefore not “does the state contain information?” but:

> How small can a replacement consumer be while still converting accessible information into better predictions on the actual task?

That question is dependency-driving: establish the bounded readout result, settle shared-subspace and sufficiency boundaries that can be proved first, establish a reproducible historical baseline, then use that baseline for controlled optimizer comparisons and later return to approximate shared-subspace questions.

## Why this page is intentionally conservative

Active research can change quickly. A wiki page should not become a second private task tracker. The authoritative public frontier is the **Current edge** section of [CHRONOLOGY.md](https://github.com/pH34r-pH/research-notes/blob/main/CHRONOLOGY.md); issues contain implementation planning; a new numbered notebook appears only after result and interpretation stabilize.
